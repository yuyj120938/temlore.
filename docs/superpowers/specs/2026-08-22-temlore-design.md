# Temlore 设计规格

## 目标

Temlore 是一个写给未来自己的信件网页 App。第一版先作为手机网页 App 在本机运行验收，之后再部署到固定网址，最终再考虑原生 App。

设计基准为 iPhone 15（393 × 852），适配常见手机宽度。

## 核心流程

启动动画 → Start 首页 → 登录（未登录时）→ 信封打开 → 写信 → 选择封存时间 → 封存入柜动画 → 时间侧栏 → 书桌抽屉 → 火漆开信 → 阅读。

启动动画约 3 秒：纯白背景上有淡化彩色圆形缓慢漂浮；蓝色蜡滴落下，正圆火漆压出钟表，Logo 中的 `o` 被火漆替代，随后 `Teml` 与 `re` 逐字出现。

## 页面与交互

### 首页

- 启动动画结束后进入首页，不重复播放。
- 首页使用中英混排、编辑式大标题、信封主体、纯白背景和彩色圆形。
- 主按钮为 `Start writing`。
- 左上角进入登录；登录后变为账号与信件时间入口。
- 未登录点击 `Start writing`，先登录，成功后自动继续信封打开动画。

### 登录

- 独立全屏页面，从首页左上角进入。
- 手机号＋密码登录，不发送短信。
- 使用参考图式的交错胶囊输入框、半透明控件和底部拱门构图。
- 注册成功后生成一次性恢复码；恢复码与密码同时遗失时无法恢复。

### 开信与编辑

- 首页信封放大到中央，封口打开，信纸抽出。
- 最终为纯白独立信纸，四周保留窄缝并可看到背景，带轻微圆角和阴影。
- 支持真实文字输入；整封信统一切换宋体或楷体。
- 照片完全可选，最多 9 张，自动压缩。
- 照片插入正文后使用拍立得式暖白纸框，可填写说明；未添加照片时不显示占位框。
- 草稿停止输入约 1 秒自动保存。

### 封存

- 采用环形时间轨道，提供 10 秒、1 天、7 天、30 天、1 年和自选日期。
- 确认封存后正文和照片不可查看、编辑或改期；仅允许二次确认删除。
- 入柜动画：折纸 → 入信封 → 合盖 → 蓝色蜡滴 → 不透明规则正圆蓝色火漆 → 推入书桌抽屉。

### 时间侧栏与书桌

- 左侧按写信时间显示草稿、封存中、已到达、已开启。
- 选中一封已到达信后进入书桌。
- 书桌页面背景纯白；书桌物件使用 `#E8E1D5`，抽屉用更深同色层次。
- 中央抽屉一次只推出当前选中的信封。
- 点击火漆后展开信纸。首次开启后永久为已开启，之后可随时阅读。

## 视觉系统

- 页面背景：`#FFFFFF`。
- 火漆：`#B2EEFF`，规则正圆且不透明。
- 火漆钟表数字、指针与压印：`#98C6FF`。
- 信纸、信封：纯白或轻微象牙白，仅通过边框和阴影区分。
- 书桌：`#E8E1D5`，抽屉深色同色阶；不使用蜂蜜木或大面积淡黄色页面底色。
- 动效以有重量的缓动为主，普通操作 200–400ms，仪式动画 1.5–5s。
- 支持系统“减少动态效果”。

## 数据与保护

- 第一版使用本地服务模拟云端结构：账号、信件状态和照片文件分层保存。
- 服务端时间决定是否到期，不能通过修改手机时间提前开启。
- 密码和恢复码只保存哈希。
- 第一版使用常规云端保护，不宣称端到端加密。
- 到期提醒第一版仅在登录 App 内显示红点和提示；后续再加入浏览器通知。

## 验收标准

- 手机端布局与动画在 393 × 852 基准下清晰可用。
- 启动、开信、封存、入柜、开信动画顺序正确，关键物件连续。
- 所有背景纯白；所有火漆为蓝色；Logo 火漆略大于 `r`，内部钟表约占火漆直径三分之二。
- 多封信状态互不干扰；封存期间不可读；到期后可从时间侧栏进入抽屉并永久阅读。
- 本机验收通过后，再进入部署和云端替换阶段。
