# Temlore 局部交互调整设计

## 范围

本轮只修改 Start、写信、时间选择和入信动画四处，不重做已经确认的整体视觉、配色与页面结构。所有交互继续以 393 × 852 手机页面为基准。

## Start 页历史信件入口

- 点击左上角入口后，从屏幕左侧滑入历史信件抽屉。
- 抽屉宽度为手机屏幕约三分之二，使用圆角、略透明背景和轻微背景模糊。
- Start 页留在抽屉下方，不跳转到独立历史页面。
- 抽屉内只显示真实保存的写信时间，不显示额外的“点击查看”方框。
- 点击写信时间直接打开对应信件；点击抽屉外区域或返回按钮关闭抽屉。

## 写信与草稿

- 底部工具栏持续显示宋体/楷体切换、照片添加和完成按钮。
- 返回按钮立即回到 Start 页，不播放页面过场。
- 正文、字体和照片布局实时保存到本机；再次进入恢复上次草稿。
- 照片通过手机相册或文件选择器添加。
- 照片支持双指等比例缩放，并支持拖拽四角自由调整宽高。
- 照片最大尺寸不超过白纸内容区域，不能溢出手机屏幕。

## 时间选择

- 预设时间仅保留：10 秒、一周、六个月、一年。
- 点击预设后，指针以圆心为轴顺时针旋转到对应刻度，并使用平滑缓动动画。
- 从一年切回较短时间时仍沿顺时针方向继续旋转，不反向倒转。
- 自定义日期控件使用圆角紫色描边；选中日期与主要选中状态使用现有背景蓝色。
- 返回按钮立即回到写信页面。

## 入信动画

- 保留折纸、装入信封、合盖和蓝色火漆顺序。
- 动画中的书桌沿用 Start/到达信件页面的暖灰书桌颜色与抽屉造型。
- 信封封好后，先拉开抽屉，再把信封放入，最后关闭抽屉。
- 动画完成后返回 Start 页。

## 数据与验证

- 沿用 localStorage，不增加服务端或新依赖。
- 草稿照片在本机以可恢复的数据形式保存，避免刷新后失效的临时对象 URL。
- 添加组件测试验证草稿恢复、时间预设和顺时针指针状态。
- 使用 393 × 852 Playwright 手机视口验证侧滑抽屉、写信工具栏、时间选择和入抽屉动画链路。
